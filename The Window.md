# The Window

**The Window** is the open interval in which a world can still choose — the span of [[Time]] during which the leap from the [[Old]] to the [[New]] remains possible before [[Collapse]] closes the way.

No one knows how long The Window will remain open. It did not open on a schedule and it will not close on one. Its edges are not visible from within it. What is knowable is that it *is* open now, that it has been closing, and that every season spent feeding the old pattern narrows it further.

This changes how time itself is held:

- **The Window is not a deadline.** Deadlines belong to [[Temporal Markers]] — the milestones we set to manage our own work. The Window is set by reality, not by us; it cannot be renegotiated, extended, or appealed.
- **Contingency assumes The Window stays open.** A plan that runs late intends to consume its reserves — but reserves can only be spent inside an open Window. If The Window closes first, the contingency was never really there. This is why lateness on the [[Critical Path]] is never merely a schedule problem.
- **The Window is read, not calculated.** Because [[We Do Not Know]], the width of The Window is a continual matter of sense-making, discernment, and [[OmniSpection]] — watching the [[Non-Zero Probability of Systems Collapse]], the signs of the times, and the quiet signals beneath them, season after season, and acting accordingly.
- **Therefore: act as if.** The wise stance within an unknowable Window is to [[Act As If]] it could close at any time — moving as rapidly as possible toward [[Proper Order]], [[Without Harm or Disadvantage to Any]], while never despairing, because the same unknowability that could close The Window early also means grace may hold it open longer than any calculation allows.

The Window is why urgency and peace must live together. Urgency, because the interval is real and finite. Peace, because panic feeds the very collapse that closes it — and because the work goes fastest when done in the spirit of the world it is building.
