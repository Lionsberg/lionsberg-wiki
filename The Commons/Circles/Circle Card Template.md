# Circle Card Template

*Copy this file to create your Circle's card: `The Commons/Circles/<Circle Name>.md`. Circles stand visibly, formed of Players who stand — so the Game can see itself grow. One name, one card; if your Circle's name is already burning elsewhere, add your place: `Circle of the Sacred Flame (Melbourne)`.*

```
# <Circle Name>
place:: <where in the world>
region:: <for the directory: country or region>
open:: <yes, if welcoming new members — the directory shows you to Players gathering nearby>
formed:: <date the Circle was sealed>
lineage:: [[<the Circle that passed you the flame>]]
players:: <the Players standing in this Circle — link their [[Player Card Template|Player cards]]>
agreements:: <your 2–5 simple agreements>
rhythm:: <when you meet>
quest:: [[<current Quest>]]
state:: rooting | playing | harvesting | resting
```

*Then add one row for your Circle to [[The Gameboard]].*
