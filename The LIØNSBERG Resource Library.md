## Digital Platform Tools

1. Decision-Making & Governance

These tools help groups avoid endless email chains and reach a clear consensus democratically.

- **[Loomio](https://www.loomio.com/)**: A robust platform specifically designed for collaborative decision-making. It allows local groups to host discussions, run proposals, vote on community initiatives, and cleanly document outcomes without messy chat threads.
- **[Decidim](https://decidim.org/)**: A comprehensive, open-source participatory democracy framework used by city municipalities and large grassroots movements alike. It supports citizen initiatives, participatory budgeting, public consultations, and strategic planning.

2. Team Communication & Daily Coordination

For fast-paced, daily chat, file sharing, and task management, these tools keep localized working groups aligned. 

- **[Mattermost](https://mattermost.com/)**: A powerful, privacy-first, open-source alternative to Slack. It can be entirely self-hosted by your local group to ensure community discussions and shared data remain private and under your own control. 
- **[Element / Matrix](https://element.io/)**: A secure, decentralized messaging application built on the open Matrix protocol. It is ideal for local organizing networks because it allows different communities to interoperate securely across encrypted chatrooms. 
- **[Nextcloud](https://nextcloud.com/)**: A self-hosted productivity suite that replaces Google Drive. It bundles cloud file storage, shared community calendars, collaborative document editing, and project task boards into a single, cohesive hub.

3. Local Networking & Resource Sharing

These platforms specialize in mapping local resources, sharing physical goods, and cross-pollinating ideas between neighboring towns.

- **[Kumu](https://kumu.io/)**: A powerful data-visualization tool used to map complex relationships, local stakeholders, and resource flows within a town. It helps communities visualize their local network assets to build resilient coalitions.
- **Karrot**: A specialized, open-source tool designed explicitly for grassroots resource sharing and food-saving initiatives. It operates entirely without money or ads, focusing instead on community-driven logistics and volunteer coordination.

4. Knowledge Management & Project Wikis

When your group needs a centralized repository to store meeting minutes, local history, or ecological project blueprints. 

- **[MediaWiki](https://www.mediawiki.org/)**: The same robust open-source software that powers Wikipedia. It is highly customizable and best suited for mature community groups that need a deep, hyper-local knowledge commons to document processes.
- **[BookStack](https://www.bookstackapp.com/)**: A modern, highly intuitive, and organizer-friendly wiki platform. It organizes community guides, resource documents, and onboarding material into a familiar "Books, Chapters, and Pages" layout that is accessible to non-technical volunteers.
- **[MarkPub](https://markpub.org)**: The technology behind the [[LIØNSBERG Wiki]]
